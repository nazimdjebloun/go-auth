# Invite-Only Mode

When invite-only mode is enabled, registration requires a valid invite code. This is controlled via `WithRegistration`:

```go
goauth.WithRegistration(goauth.RegistrationConfig{
    EnableInvite: true,
    AllowPublic:  false, // gate all public registration
})
```

When `AllowPublic` is `false` and `EnableInvite` is `true`, only users with an invite code can register. Set `AllowPublic` to `true` to allow public registration alongside invite codes.

The flow:

1. Admin creates invite → email sent with code
2. User clicks link → frontend opens registration form with code
3. User submits → `POST /auth/invite/register` with `{code, name, password}`
