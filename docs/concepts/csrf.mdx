# CSRF Protection

go-auth uses the **double-submit cookie** pattern:

1. On first GET, a `csrf_token` cookie is set
2. For state-changing requests (POST, PUT, DELETE, PATCH), the client reads the cookie value and sends it in an `X-CSRF-Token` header
3. The server verifies the header matches the cookie

CSRF is enforced on all state-changing auth routes. Disabled by default — enable via `WithSecurity`:

```go
goauth.WithSecurity(goauth.SecurityConfig{
    CSRFToken: &middleware.CSRFTokenConfig{
        CookieName: "csrf_token",
        HeaderName: "X-CSRF-Token",
        Secure:     true,
    },
})
```
