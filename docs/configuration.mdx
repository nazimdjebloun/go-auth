# Configuration

## Minimal Config

The minimum required fields:

```go
cfg, err := goauth.NewConfig(
    goauth.WithApp(goauth.AppConfig{
        Name:    "MyApp",              // used in email subjects
        BaseURL: "http://localhost:3000", // frontend base URL
        Database: goauth.DatabaseConfig{
            URL: "postgres://user:pass@localhost:5432/dbname",
        },
    }),
    goauth.WithSecurity(goauth.SecurityConfig{
        AllowedOrigins: []string{"http://localhost:3000"},
    }),
)
```

## Full Config

### Application

```go
goauth.WithApp(goauth.AppConfig{
    Name:    "MyApp",   // default "App"
    BaseURL: "http://localhost:3000", // required
})
```

### Database

```go
type DatabaseConfig struct {
    URL    string          // connection string (preferred)
    DB     *sql.DB         // pre-opened *sql.DB
    Pool   *pgxpool.Pool   // pre-opened pgx pool
    Driver Driver          // "postgres" (default), "sqlite3", "mysql"
}
```

Provide exactly one of `URL`, `DB`, or `Pool`.

### Password Policy

```go
goauth.WithSecurity(goauth.SecurityConfig{
    PasswordPolicy: domain.PasswordPolicy{
        MinLength:    8,      // default 8
        RequireDigit: true,   // default true
    },
})
```

### Sessions

| Field | Default | Description |
|---|---|---|
| `Session.TTL` | 720h (30d) | Absolute session expiry |
| `Session.IdleTTL` | 168h (7d) | Idle timeout |
| `Session.RefreshTokenTTL` | 720h (30d) | Refresh token lifetime |
| `Session.MaxLifetime` | 0 (no limit) | Max session lifetime from creation |
| `Session.GraceWindow` | 10s | Grace period for refresh token reuse |
| `Session.TouchDebounce` | 5m | Min interval between last_active_at writes |
| `Security.TokenTTL` | 1h | Verification/reset token duration |

### Cookie

```go
goauth.WithCookie(goauth.CookieConfig{
    Name:     "goauth_session",       // default
    Domain:   "",                     // empty = current domain
    Path:     "/",                    // default
    Secure:   false,                  // auto-derived from BaseURL scheme
    SameSite: http.SameSiteLaxMode,  // default
})
```

### Registration

Controls which registration methods are available. Login is always unconditional regardless of these flags.

```go
goauth.WithRegistration(goauth.RegistrationConfig{
    EnableEmailPassword:           true,   // email+password signup (default true)
    EnableOAuth:              true,   // OAuth signup for new users (default true)
    EnableInvite:             true,   // invite-code registration (default true)
    AllowPublic:              true,   // allow public registration (default true)
    RequireEmailVerification: false,  // require email verification on signup (default false)
    InviteTTL:                7 * 24 * time.Hour,    // how long invite codes last (default 7d)
    VerificationCodeTTL:      15 * time.Minute,      // verify code lifetime (default 15m)
})
```

When `AllowPublic` is `false`, registration is gated — only invited users or OAuth users (if `EnableOAuth` is `true`) can sign up.

| Field | Default | Description |
|---|---|---|
| `EnableEmailPassword` | `true` | Email + password registration |
| `EnableOAuth` | `true` | OAuth signup for new users |
| `EnableInvite` | `true` | Invite-code registration |
| `AllowPublic` | `true` | Public registration allowed |
| `RequireEmailVerification` | `false` | Verify email on signup |
| `InviteTTL` | 168h (7d) | Invite code lifetime |
| `VerificationCodeTTL` | 15m | Verification code lifetime |

### Email & Verification

```go
type EmailConfig struct {
    Host    string   // SMTP host, required
    Port    int      // SMTP port, required, 1-65535
    User    string   // SMTP username, optional
    Pass    string   // SMTP password, optional (must be set together with User, or both empty)
    From    string   // sender address, required, must be a valid email address
    TLSMode TLSMode  // TLSNone, TLSStart, or TLSImplicit
}
```

```go
// Option 1: SMTP config
goauth.WithEmail(goauth.EmailConfig{
    Host:    "smtp.example.com",
    Port:    587,
    User:    "user",
    Pass:    "pass",
    From:    "noreply@example.com",
    TLSMode: goauth.TLSStart, // STARTTLS (port 587)
})

// Option 2: Custom mailer
goauth.WithMailer(myMailer) // implements port.Mailer
```

#### TLSMode

| Constant | Use When |
|---|---|
| `goauth.TLSNone` | Plaintext SMTP — dev/local only, never production |
| `goauth.TLSStart` | STARTTLS upgrade — typical for port 587 with auth |
| `goauth.TLSImplicit` | Implicit TLS from the start — typical for port 465 |

Email or a custom mailer is required when `RequireEmailVerification` or `EnableInvite` is `true`.

### Organizations

```go
goauth.WithOrganizations(goauth.OrganizationConfig{
    Enable:         true,
    MaxOrgsPerUser: 10,              // 0 = default 100, max 100
    InviteTTL:      24 * time.Hour, // default 7d
})
```

### Security

```go
goauth.WithSecurity(goauth.SecurityConfig{
    AllowedOrigins:          []string{"http://localhost:3000", "https://myapp.com"},
    AllowMissingCSRFHeaders: false,
    CSRFToken: &middleware.CSRFTokenConfig{
        CookieName: "csrf_token",
        HeaderName: "X-CSRF-Token",
        Secure:     true,
    },
})

// Rate limiting — granular options (recommended)
goauth.WithRateLimitEnabled(true),

// Or full replace for complete control:
goauth.WithRateLimit(ratelimit.Config{
    Enabled: true,
    // ... full config
})
```

### Signing Secret

```go
goauth.WithSecret("0123456789abcdef0123456789abcdef") // >= 32 bytes, HMAC-SHA256
```

`WithSecret` sets the app-wide signing key used for CSRF tokens (and future HMAC tokens). Required when using CSRF protection. **Never hardcode it** — load from the environment.

### Audit Logging

```go
goauth.WithAudit(goauth.AuditConfig{
    Enabled:       true,
    RetentionDays: 90,                 // 0 = keep forever
    QueueSize:     1000,               // default
    Workers:       3,                  // default
    BatchSize:     50,                 // default
    FlushInterval: 100 * time.Millisecond, // default
})

// Optional custom sink (Kafka, NATS, webhook, ...)
goauth.WithAuditSink(mySink) // implements audit.EventSink
```

When enabled, security events (login, logout, registration, password changes, session revocations, admin actions, OAuth, org events) are queued and flushed to sinks — by default the built-in `audit.SQLAuditSink` persists them to the `audit_logs` table. Exposed to admins via `GET /admin/audit-logs` and `GET /admin/users/{id}/audit-logs` (returns `404 audit_not_configured` when disabled).

### OAuth Providers

```go
goauth.WithProvider(google.New(google.Config{...}))
goauth.WithProvider(github.New(github.Config{...}))
```

Multiple providers are supported. Each must have a unique `Name()`.

### Logging

```go
goauth.WithLogger(slog.New(slog.NewJSONHandler(os.Stdout, nil)))
// default: slog.Default()
```

## Using NewConfig

`NewConfig` applies option functions to `DefaultConfig()` and validates:

```go
cfg, err := goauth.NewConfig(
    goauth.WithApp(goauth.AppConfig{
        Name:    "MyApp",
        BaseURL: "http://localhost:3000",
        Database: goauth.DatabaseConfig{
            URL: "postgres://...",
        },
    }),
    goauth.WithSecurity(goauth.SecurityConfig{
        AllowedOrigins: []string{"http://localhost:3000"},
    }),
    goauth.WithOrganizations(goauth.OrganizationConfig{
        Enable: true,
    }),
    goauth.WithProvider(github.New(github.Config{...})),
)
```

If validation fails, `err` aggregates all invalid fields via `errors.Join`. Example error:

```text
database: driver cannot be empty
base_url must be a valid HTTP or HTTPS URL
session_ttl must be positive
```

## Validation Rules

| Field | Rule |
|---|---|
| `App.Database.Driver` | Must not be empty |
| `App.Database` | One of URL, DB, or Pool required |
| `App.Name` | Must not be empty |
| `App.BaseURL` | Valid http/https URL |
| `Session.TTL` | Positive |
| `Session.IdleTTL` | Positive, ≤ Session.TTL |
| `Session.RefreshTokenTTL` | Positive, ≥ Session.TTL |
| `Security.AllowedOrigins` | At least one origin, no wildcards |
| `Security.TokenTTL` | Positive |
| `Cookie.Name` | Not empty |
| Email config | Required if `Registration.RequireEmailVerification` or `Registration.EnableInvite` is true |
| `Email.Host` | Required (when Email config is set) |
| `Email.Port` | 1–65535 (when Email config is set) |
| `Email.From` | Required, must be a valid email address (when Email config is set) |
| `Email.User` / `Email.Pass` | Both set or both empty (when Email config is set) |
| `Email.TLSMode` | Must be TLSNone, TLSStart, or TLSImplicit (when Email config is set) |
| `Registration.RequireEmailVerification` | Has no effect when both `EnableEmailPassword` and `EnableOAuth` are false |
| `Registration.AllowPublic` | At least one of `EnableEmailPassword`, `EnableOAuth`, `EnableInvite` must be true |
| `Organization.MaxOrgsPerUser` | 0–100 |
| Providers | Non-nil, unique names |
| `RateLimit.Default.Requests` | Positive (when enabled) |
| `RateLimit.Default.Window` | Positive (when enabled) |
| `RateLimit.Routes.*.Requests` | Positive (when enabled) |
| `RateLimit.Routes.*.Window` | Positive (when enabled) |
| `RateLimit.IPv6Subnet` | 1–128 (when enabled) |
| `RateLimit.TrustedIPs` | Valid IP or CIDR (when enabled) |
| `RateLimit.IPAddressHeader` | Requires non-empty `TrustedIPs` (when enabled) |
| `RateLimit.Store` | Non-nil (when enabled) |
