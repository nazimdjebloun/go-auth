# Getting Started

This guide walks through setting up go-auth with PostgreSQL in under 5 minutes.

## 1. Create a Config

```go
package main

import (
    "log"
    "net/http"
    "os"

    "github.com/nazimdjebloun/go-auth"
    "github.com/nazimdjebloun/go-auth/provider/google"
    "github.com/nazimdjebloun/go-auth/provider/github"
)

var Auth *goauth.Auth

func initAuth() {
    cfg, err := goauth.NewConfig(
        goauth.WithApp(goauth.AppConfig{
            Name:    os.Getenv("APP_NAME"),
            BaseURL: os.Getenv("BASE_URL"),
            Database: goauth.DatabaseConfig{
                URL: os.Getenv("DATABASE_URL"),
            },
        }),
        goauth.WithCookie(goauth.CookieConfig{
            Domain: os.Getenv("COOKIE_DOMAIN"),
            Secure: os.Getenv("ENV") == "production",
        }),
        goauth.WithProvider(google.New(google.Config{
            ClientID:     os.Getenv("GOOGLE_CLIENT_ID"),
            ClientSecret: os.Getenv("GOOGLE_CLIENT_SECRET"),
            RedirectURL:  os.Getenv("GOOGLE_REDIRECT_URL"),
        })),
        goauth.WithProvider(github.New(github.Config{
            ClientID:     os.Getenv("GITHUB_CLIENT_ID"),
            ClientSecret: os.Getenv("GITHUB_CLIENT_SECRET"),
            RedirectURL:  os.Getenv("GITHUB_REDIRECT_URL"),
        })),
    )
    if err != nil {
        log.Fatalf("goauth config invalid: %v", err)
    }

    Auth, err = goauth.New(cfg)
    if err != nil {
        log.Fatalf("goauth init failed: %v", err)
    }
}
```

## 2. Mount Routes

```go
func main() {
    initAuth()
    mux := http.NewServeMux()
    Auth.Mount(mux)
    log.Fatal(http.ListenAndServe(":8080", mux))
}
```

That's it. All auth routes are live.

## 3. Using Handlers Directly

Skip `Mount()` and register handlers yourself:

```go
func main() {
    initAuth()
    mux := http.NewServeMux()

    mux.HandleFunc("POST /auth/register", Auth.Handlers.Register)
    mux.HandleFunc("POST /auth/login", Auth.Handlers.Login)
    mux.HandleFunc("GET /auth/me", Auth.Handlers.GetMe)
    mux.HandleFunc("GET /protected", Auth.Middleware.Authenticate(myProtectedHandler))

    log.Fatal(http.ListenAndServe(":8080", mux))
}
```

## 4. Programmatic Usage

Call auth logic without HTTP:

```go
func createUser(ctx context.Context, email, password, name string) {
    result, err := Auth.Register(ctx, goauth.RegisterInput{
        Email:    email,
        Password: password,
        Name:     name,
    })
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("Created user %s", result.User.ID)
}
```

## 5. Enable Organizations

```go
goauth.WithOrganizations(goauth.OrganizationConfig{
    Enable:         true,
    MaxOrgsPerUser: 10,
    InviteTTL:      48 * time.Hour,
})
```
