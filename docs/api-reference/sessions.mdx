# Session Handlers

## Routes

| Method | Path | Middleware |
|---|---|---|
| GET | `/auth/sessions` | Auth |
| GET | `/auth/sessions/all` | Auth |
| DELETE | `/auth/sessions/{id}` | Auth + CSRF + Origin |
| POST | `/auth/sessions/revoke` | Auth + CSRF + Origin |
| DELETE | `/auth/sessions` | Auth + CSRF + Origin |

## Session Object

All endpoints return `domain.Session` objects serialized with snake_case JSON. Hash fields (`token_hash`, `refresh_token_hash`, `previous_refresh_hash`) are never serialized.

```json
{
  "id": "3f2a...",
  "user_id": "b1d0...",
  "ip_address": "203.0.113.7",
  "user_agent": "Mozilla/5.0 ...",
  "parsed_ua": {
    "browser": "Chrome",
    "browser_version": "125.0",
    "os": "Windows",
    "os_version": "11",
    "device_type": "desktop"
  },
  "is_revoked": false,
  "expires_at": "2026-08-01T12:00:00Z",
  "refresh_expires_at": "2026-08-28T12:00:00Z",
  "refresh_rotated_at": "2026-07-31T12:00:00Z",
  "created_at": "2026-07-31T12:00:00Z",
  "last_active_at": "2026-07-31T12:30:00Z",
  "active_org_id": null,
  "active_org_role": null
}
```

- `parsed_ua` is populated at login from the `User-Agent` header and omitted (`null`) when no user agent was captured. It powers device/browser icons in session-management UIs.
- List endpoints only return **active** sessions (`is_revoked = false` and not past `expires_at`).

## Handlers

### `GET /auth/sessions`

**Auth required.** Returns the current user's active sessions, paginated.

Query params:

| Param | Default | Max |
|---|---|---|
| `offset` | `0` | — |
| `limit` | `20` | `100` |

```json
{
  "sessions": [ /* Session */ ],
  "total": 4,
  "limit": 20,
  "offset": 0,
  "current_session_id": "3f2a..."
}
```

`current_session_id` identifies the session making this request (useful for highlighting the current device and disallowing its own revoke).

### `GET /auth/sessions/all`

**Auth required.** Returns the current user's **all** active sessions with no pagination.

```json
{
  "sessions": [ /* Session */ ],
  "current_session_id": "3f2a..."
}
```

Use this for "manage all devices" screens that don't need paging.

### `DELETE /auth/sessions/{id}`

**Auth required.** Revokes a single session **owned by the current user**.

- The session ID is validated as a UUID first; malformed or foreign IDs return `404`.
- If the session belongs to another user, it is not revoked — returns `404`.

```json
{ "message": "Session revoked" }
```

Errors: `404 session_not_found` — no such session or not owned by the caller.

### `POST /auth/sessions/revoke`

**Auth required.** Revokes multiple sessions owned by the current user in one call.

Request body (1–100 IDs, duplicate/foreign/malformed IDs are silently skipped):

```json
{ "session_ids": ["3f2a...", "9c1e..."] }
```

Response — `revoked` is the number of sessions actually deleted:

```json
{ "revoked": 2 }
```

Errors: `400 invalid_input` — empty array or more than 100 IDs.

### `DELETE /auth/sessions`

**Auth required.** Revokes **all other** sessions for the current user, keeping the current session (the one making the request) intact.

```json
{ "message": "Sessions revoked" }
```

If the current session cannot be resolved, all sessions are revoked.

## Middleware Notes

- Listing (`GET`) endpoints are wrapped with `Auth` only.
- Mutation (`DELETE`/`POST`) endpoints are wrapped with `Auth + CSRF + Origin`, matching the CSRF double-submit cookie flow.
