## Handlers

### `POST /auth/orgs`

**Auth + RateLimit.** Request: `{ "name": "Acme", "slug": "acme" }`. Response 201.

### `GET /auth/orgs`

**Auth.** Returns `[Organization]`.

### `GET /auth/orgs/{orgID}`

**Auth.** Returns `Organization`.

### `PUT /auth/orgs/{orgID}`

**Auth + CSRF.** Request: `{ "name": "Acme Inc", "slug": "acme-inc" }`. Response 200.

### `DELETE /auth/orgs/{orgID}`

**Auth + CSRF.** Response 200.

### `GET /auth/orgs/{orgID}/members`

**Auth.** Query: `?offset=0&limit=20`. Returns `{ "members": [...], "total": N }`.

### `DELETE /auth/orgs/{orgID}/members/{userID}`

**Auth + CSRF.** Response 200.

### `PATCH /auth/orgs/{orgID}/members/{userID}/role`

**Auth + CSRF.** Request: `{ "role": "admin" }`. Response 200.

### `POST /auth/orgs/{orgID}/leave`

**Auth + CSRF.** Response 200.

### `PUT /auth/orgs/active`

**Auth + CSRF.** Request: `{ "orgId": "..." }`. Response 200.

### `DELETE /auth/orgs/active`

**Auth + CSRF.** Response 200.

### `POST /auth/orgs/{orgID}/invites`

**Auth + RateLimit.** Request: `{ "email": "b@b.com", "role": "member" }`. Response 201.

### `POST /auth/orgs/invites/accept`

**Auth.** Request: `{ "code": "..." }`. Response 200.

### `GET /auth/orgs/{orgID}/invites`

**Auth.** Returns `[OrgInvite]`.

### `POST /auth/orgs/{orgID}/invites/{inviteID}/resend`

**Auth + CSRF.** Response 200.

### `DELETE /auth/orgs/{orgID}/invites/{inviteID}`

**Auth + CSRF.** Response 200.
