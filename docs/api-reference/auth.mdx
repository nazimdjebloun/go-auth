|---|---|---|
| POST | `/auth/register` | RateLimit + CSRF + Origin |

| POST | `/auth/login` | RateLimit + CSRF + Origin |
| POST | `/auth/signin` | RateLimit + CSRF + Origin |
| POST | `/auth/logout` | Auth + CSRF + Origin |
| POST | `/auth/signout` | Auth + CSRF + Origin |

## Handlers

### `POST /auth/register`

**Request:**
```json
{ "email": "a@b.com", "password": "str0ng!", "name": "Alice" }
```
**Response 201:** `RegisterResult` — user, session, sessionToken, refreshToken, requiresVerification

### `POST /auth/login`

**Request:**
```json
{ "email": "a@b.com", "password": "str0ng!" }
```
**Response 200:** `LoginResult` — user, session, sessionToken, refreshToken, requiresVerification

### `POST /auth/logout`

**Auth required.** No body. Response 200.

### `GET /auth/me`

**Auth required.** Returns `User` object.

### `GET /auth/check`

Accepts `?token=...` query param or `Authorization: Bearer ...` header. Response 200 `{ "valid": true/false }`.

### `DELETE /auth/account`

**Auth + CSRF + Origin.** Request: `{ "password": "..." }`. Response 200.

### `POST /auth/account/delete/request`

**Auth + RateLimit.** Sends delete confirmation code to user email. Response 200.

### `POST /auth/account/delete/confirm`

**Auth + RateLimit.** Request: `{ "code": "..." }`. Response 200.

### `PUT /auth/name`

**Auth.** Request: `{ "name": "Alice" }`. Response 200.

### `POST /auth/refresh`

Request: `{ "refreshToken": "..." }`. Response 200 with new session.

### `GET /auth/csrf-token`

Response 200: `{ "csrfToken": "..." }`. Sets CSRF cookie.
