# Admin Handlers

All routes require the caller to be authenticated **and** have role `admin` (`Auth + Admin`).

## Handlers

### `GET /admin/users`

**Auth + Admin.** Query: `?offset=0&limit=20&email=&search=&role=&orderBy=created_at&orderDirection=desc`. Returns `AdminListUsersResult`.

### `GET /admin/users/{id}`

**Auth + Admin.** Returns full detail for one user (`AdminUserDetail`), including session and login metadata.

### `POST /admin/users`

**Auth + Admin.** Request: `CreateUserInput`. Response 201.

### `PATCH /admin/users/{id}/role`

**Auth + Admin.** Request: `{ "role": "admin" }`. Response 200.

### `PATCH /admin/users/{id}/ban` / `.../{id}/unban`

**Auth + Admin.** Response 200.

### `DELETE /admin/users/{id}`

**Auth + Admin.** Response 200.

### `GET /admin/users/{id}/sessions`

Query: `?offset=0&limit=20`. Returns `{ "sessions": [Session], "total": N }`. The session objects include `parsed_ua` for device display.

### `DELETE /admin/users/{id}/sessions/{sessionId}`

Revokes a single session for the user. The revoke is **user-scoped** — it only takes effect if the session actually belongs to `{id}`; otherwise `404 session_not_found`. Response 200.

### `DELETE /admin/users/{id}/sessions`

Revokes all sessions for user. Response 200.

### `GET /admin/audit-logs`

**Auth + Admin.** Returns security audit events, newest first. Available only when audit logging is enabled (see configuration); otherwise `404 audit_not_configured`.

Query params (all optional):

| Param | Meaning |
|---|---|
| `offset` / `limit` | Pagination (default `0` / `50`, max `200`) |
| `event_type` | Filter by event type, e.g. `login.success` |
| `actor_id` | Events where this user performed the action |
| `target_user_id` | Events targeting this user |
| `session_id` | Events for a specific session |
| `org_id` | Events for a specific org |
| `search` | Free-text search over metadata/agent |
| `from` / `to` | RFC3339 timestamp range |
| `success` | `true` / `false` |

```json
{
  "events": [ /* audit.Event */ ],
  "total": 137,
  "limit": 50,
  "offset": 0
}
```

### `GET /admin/users/{id}/audit-logs`

Same as above, pre-filtered to `target_user_id = {id}`.

### `POST /admin/invites`

Request: `{ "email": "a@b.com" }`. Response 201.

### `GET /admin/invites`

Query: `?offset=0&limit=20&search=&status=`. Response: `{ "invites": [...], "total": N }`.

### `DELETE /admin/invites/{id}`

Revokes invite. Response 200.

### `POST /admin/invites/{id}/resend`

Response 200.

### `DELETE /admin/invites/{id}/hard`

Hard deletes (not just revoke). Response 200.
