## Routes

| Method | Path | Middleware |
|---|---|---|
| POST | `/auth/forgot-password` | RateLimit + CSRF + Origin |
| POST | `/auth/reset-password` | RateLimit + CSRF + Origin |
| PUT | `/auth/password` | Auth + CSRF + Origin |
| POST | `/auth/change-password` | Auth + CSRF + Origin |
| POST | `/auth/set-password/request` | RateLimit + Auth + CSRF + Origin |
| POST | `/auth/set-password/confirm` | RateLimit + Auth + CSRF + Origin |

## Handlers

### `POST /auth/forgot-password`

**Rate limited.** Request: `{ "email": "a@b.com" }`. Response 200.

### `POST /auth/reset-password`

**Rate limited.** Request: `{ "code": "...", "password": "newStr0ng!" }`. Response 200.

### `PUT /auth/password` / `POST /auth/change-password`

**Auth + CSRF.** Request: `{ "oldPassword": "...", "newPassword": "..." }`. Response 200.
