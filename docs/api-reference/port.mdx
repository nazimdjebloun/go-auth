# port Package

`import "github.com/nazimdjebloun/go-auth/port"`

## Repository Interfaces (Database)

### UserRepository

```go
type UserRepository interface {
    Create(ctx, user *domain.User) error
    GetByID(ctx, id string) (*domain.User, error)
    GetByEmail(ctx, email string) (*domain.User, error)
    Update(ctx, user *domain.User) error
    Delete(ctx, id string) error
    List(ctx, ListUsersInput) ([]domain.User, int, error)
    Ban(ctx, id string) error
    Unban(ctx, id string) error
    UpdateRole(ctx, id string, role domain.Role) error
    IncrementOrgOwnerCount(ctx, id string) error
    DecrementOrgOwnerCount(ctx, id string) error
}
```

## Service Interfaces

### Mailer

```go
type Mailer interface {
    Send(ctx, to, template string, data map[string]interface{}) error
}
```

The library calls `templates/send-email-verification.gohtml`, `templates/send-password-reset.gohtml`, `templates/send-invite.gohtml`, `templates/send-org-invite.gohtml`, `templates/send-delete-account.gohtml`, `templates/send-set-password.gohtml`.
