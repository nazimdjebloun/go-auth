# Driver Support

goauth supports three database drivers. Postgres is registered automatically.
SQLite and MySQL require a blank import in your application's main package.

## PostgreSQL (default)

No extra import needed.

```go
WithApp(goauth.AppConfig{
    Database: goauth.DatabaseConfig{Driver: goauth.DriverPostgres},
})
```

## SQLite

```sh
go get modernc.org/sqlite
```

```go
import _ "modernc.org/sqlite"

WithApp(goauth.AppConfig{
    Database: goauth.DatabaseConfig{Driver: goauth.DriverSQLite},
})
```

## MySQL

```sh
go get github.com/go-sql-driver/mysql
```

```go
import _ "github.com/go-sql-driver/mysql"

WithApp(goauth.AppConfig{
    Database: goauth.DatabaseConfig{Driver: goauth.DriverMySQL},
})
```
