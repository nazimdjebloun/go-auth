# GitLab Provider

`import "github.com/nazimdjebloun/go-auth/provider/gitlab"`

```go
type Provider struct {
    // unexported fields
}

func New(cfg Config) *Provider
```

## Configuration

| Param | Description |
|---|---|
| `ClientID` | GitLab application ID |
| `ClientSecret` | GitLab application secret |
| `RedirectURL` | Must match the callback URL registered in GitLab |
| `BaseURL` | GitLab instance URL (default `"https://gitlab.com"`) |

## Methods

| Method | Signature | Description |
|---|---|---|
| `Name()` | `string` | Returns `"gitlab"` |
| `AuthURL()` | `(state, codeChallenge string) string` | GitLab OAuth authorize URL |
| `Exchange()` | `(ctx, code, codeVerifier string) (*port.OAuthProfile, error)` | Exchanges code for token and fetches user profile |

## Default Scopes

`["read_user", "openid"]`

## Registration (gitlab.com)

1. Go to GitLab → Preferences → Applications → New application
2. Set Redirect URI to `https://yourdomain.com/auth/oauth/gitlab/callback`
3. Enable scopes: `read_user`, `openid`
4. Use the Application ID and Secret in config

## Self-Hosted GitLab

Set `BaseURL` to the URL of your GitLab instance:

```go
gitlab.New(gitlab.Config{
    ClientID:     "...",
    ClientSecret: "...",
    RedirectURL:  "...",
    BaseURL:      "https://gitlab.example.com",
})
```

## Notes

- Email is marked verified if the API response includes a `confirmed_at` timestamp.
- The `/api/v4/user` endpoint returns `id`, `email`, `name`, `username`, `avatar_url`, and `confirmed_at`.
- Self-hosted GitLab CE/EE instances are fully supported via the `BaseURL` config option.
