# Apple Provider

`import "github.com/nazimdjebloun/go-auth/provider/apple"`

```go
type Provider struct {
    // unexported fields
}

func New(cfg Config) *Provider
```

## Configuration

| Param | Description |
|---|---|
| `ClientID` | Apple Services ID (from Apple Developer) |
| `ClientSecret` | Apple client secret (ES256 JWT signed with your private key) |
| `RedirectURL` | Must match the return URL in Apple Developer Console |

## Methods

| Method | Signature | Description |
|---|---|---|
| `Name()` | `string` | Returns `"apple"` |
| `AuthURL()` | `(state, codeChallenge string) string` | Apple OAuth authorize URL |
| `Exchange()` | `(ctx, code, codeVerifier string) (*port.OAuthProfile, error)` | Exchanges code and decodes user info from ID token |

## Default Scopes

`["name", "email"]`

## Registration

1. Go to Apple Developer → Certificates, Identifiers & Profiles → Identifiers → Register a Services ID
2. Enable "Sign In with Apple" and configure the return URL: `https://yourdomain.com/auth/oauth/apple/callback`
3. Note the Services ID (used as `ClientID`)
4. Generate a client secret: create an ES256 JWT signed with your private key (key ID from Apple Developer)

## Notes

- Apple does not provide a user profile API. User info (email, user ID) is decoded from the `id_token` JWT returned during token exchange.
- The `client_secret` is a self-signed JWT that must be generated by the consumer. Libraries like `github.com/tideland/golib/httputil` or custom code can generate it.
- Apple's `sub` claim is the unique, stable user identifier.
- The default display name is `"Apple User"` since Apple only provides the name on the initial user creation form.
