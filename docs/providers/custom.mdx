# Custom Provider

Implement the `OAuthProvider` interface to support any OAuth 2.0 provider.

## Interface

```go
type OAuthProfile struct {
    Provider       string  // Provider name (e.g., "apple")
    ProviderUserID string  // Provider's unique user ID
    Email          string  // User email
    Name           string  // Display name
    AvatarURL      string  // Profile picture URL
    EmailVerified  bool    // Whether provider verified the email
    AccessToken    string  // OAuth access token
    RefreshToken   string  // OAuth refresh token (if available)
    TokenExpiresAt *time.Time  // Token expiry (if available)
    Raw            map[string]any  // Raw provider response
}

type OAuthProvider interface {
    Name() string
    AuthURL(state string, codeChallenge string) string
    Exchange(ctx context.Context, code string, codeVerifier string) (*OAuthProfile, error)
}
```

## Implementation Example

```go
type AppleProvider struct {
    clientID     string
    clientSecret string
    redirectURL  string
}

func New(cfg Config) *AppleProvider {
    return &AppleProvider{
        clientID:     cfg.ClientID,
        clientSecret: cfg.ClientSecret,
        redirectURL:  cfg.RedirectURL,
    }
}

func (p *AppleProvider) Name() string {
    return "apple"
}

func (p *AppleProvider) AuthURL(state, codeChallenge string) string {
    v := url.Values{}
    v.Set("client_id", p.clientID)
    v.Set("redirect_uri", p.redirectURL)
    v.Set("response_type", "code")
    v.Set("scope", "name email")
    v.Set("state", state)
    v.Set("response_mode", "form_post")
    return "https://appleid.apple.com/auth/authorize?" + v.Encode()
}

func (p *AppleProvider) Exchange(ctx context.Context, code, codeVerifier string) (*OAuthProfile, error) {
    // Exchange code for tokens...
    return &OAuthProfile{
        Provider:       "apple",
        ProviderUserID: "apple-user-id",
        Email:          "user@example.com",
        Name:           "Jane Doe",
        EmailVerified:  true,
        AccessToken:    "...",
    }, nil
}
```

## Registration

```go
goauth.WithProvider(New(appleCfg)),
```

## Notes

- PKCE is supported via `codeChallenge` parameter in `AuthURL` and `codeVerifier` in `Exchange`
- If `EmailVerified` is true, the user is created as verified
- The `Raw` field can store provider-specific data for later use
