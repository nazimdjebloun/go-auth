# Microsoft / Azure Provider

`import "github.com/nazimdjebloun/go-auth/provider/microsoft"`

```go
type Provider struct {
    // unexported fields
}

func New(cfg Config) *Provider
```

## Configuration

| Param | Description |
|---|---|
| `ClientID` | Azure AD Application (client) ID |
| `ClientSecret` | Azure AD client secret |
| `RedirectURL` | Must match the redirect URI in Azure AD app registration |
| `Tenant` | Azure tenant ID, `"common"`, `"organizations"`, or `"consumers"` (default `"common"`) |

## Methods

| Method | Signature | Description |
|---|---|---|
| `Name()` | `string` | Returns `"microsoft"` |
| `AuthURL()` | `(state, codeChallenge string) string` | Microsoft OAuth authorize URL |
| `Exchange()` | `(ctx, code, codeVerifier string) (*port.OAuthProfile, error)` | Exchanges code for token and fetches user profile |

## Default Scopes

`["User.Read", "openid", "email", "profile"]`

## Registration

1. Go to Azure Portal → App registrations → New registration
2. Set redirect URI to `https://yourdomain.com/auth/oauth/microsoft/callback`
3. Note the Application (client) ID and generate a client secret
4. Under "Certificates & secrets", create a new client secret

## Notes

- Email is fetched from the `mail` field, falling back to `userPrincipalName`.
- The Graph API endpoint (`https://graph.microsoft.com/v1.0/me`) returns `id`, `displayName`, `mail`, `userPrincipalName`.
- Use `"common"` for multi-tenant apps, `"organizations"` for work/school accounts only, or a specific tenant ID.
