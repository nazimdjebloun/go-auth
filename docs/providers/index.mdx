# Providers

`import "github.com/nazimdjebloun/go-auth/port"`

go-auth supports OAuth 2.0 authentication via pluggable providers. Each provider implements the `port.OAuthProvider` interface:

```go
type OAuthProvider interface {
    Name() string
    AuthURL(state, codeChallenge string) string
    Exchange(ctx, code, codeVerifier string) (*OAuthProfile, error)
}
```

## Registering Providers

Use `goauth.WithProvider` in `NewConfig`:

```go
goauth.WithProvider(google.New(google.Config{...}))
goauth.WithProvider(github.New(github.Config{...}))
goauth.WithProvider(microsoft.New(microsoft.Config{...}))
goauth.WithProvider(gitlab.New(gitlab.Config{...}))
goauth.WithProvider(apple.New(apple.Config{...}))
goauth.WithProvider(slack.New(slack.Config{...}))
```
