# Slack Provider

`import "github.com/nazimdjebloun/go-auth/provider/slack"`

```go
type Provider struct {
    // unexported fields
}

func New(cfg Config) *Provider
```

## Configuration

| Param | Description |
|---|---|
| `ClientID` | Slack App client ID |
| `ClientSecret` | Slack App client secret |
| `RedirectURL` | Must match the redirect URL in Slack App settings |

## Methods

| Method | Signature | Description |
|---|---|---|
| `Name()` | `string` | Returns `"slack"` |
| `AuthURL()` | `(state, codeChallenge string) string` | Slack OAuth v2 authorize URL |
| `Exchange()` | `(ctx, code, codeVerifier string) (*port.OAuthProfile, error)` | Exchanges code and fetches user profile via auth.test + users.info |

## Default Scopes

`["identity.basic", "identity.email", "identity.avatar"]`

## Registration

1. Go to api.slack.com → Create New App → From scratch
2. Under "Features → OAuth & Permissions", add Redirect URL: `https://yourdomain.com/auth/oauth/slack/callback`
3. Add User Token Scopes: `identity.basic`, `identity.email`, `identity.avatar`
4. Use the Client ID and Client Secret from Basic Information

## Notes

- User profile is fetched in two steps: `auth.test` (gets user ID) then `users.info` (gets profile with email and avatar).
- Slack identity tokens do not expire; `TokenExpiresAt` is `nil`.
- Use the `identity.*` scopes for "Sign In with Slack". Bot scopes like `users:read` are for workspace-installed apps.
