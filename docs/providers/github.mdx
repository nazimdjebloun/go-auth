# GitHub Provider

`import "github.com/nazimdjebloun/go-auth/provider/github"`

```go
type Provider struct {
    // unexported fields
}

func New(cfg Config) *Provider
```

## Configuration

| Param | Description |
|---|---|
| `ClientID` | GitHub OAuth App client ID |
| `ClientSecret` | GitHub OAuth App client secret |
| `RedirectURL` | Must match the callback URL registered in GitHub |

## Methods

| Method | Signature | Description |
|---|---|---|
| `Name()` | `string` | Returns `"github"` |
| `AuthURL()` | `(state, codeChallenge string) string` | GitHub OAuth authorize URL |
| `Exchange()` | `(ctx, code, codeVerifier string) (*port.OAuthProfile, error)` | Exchanges code for token and fetches user profile |

## Default Scopes

`["read:user", "user:email"]`

## Registration

1. Go to GitHub → Settings → Developer settings → OAuth Apps → New OAuth App
2. Set Authorization callback URL to `https://yourdomain.com/auth/oauth/github/callback`
3. Use Client ID and Client Secret in config

## Notes

- GitHub does not return an expiry time for access tokens; `TokenExpiresAt` is `nil`.
- Email is fetched from `/user/emails` (primary, verified email) if not present in the `/user` response.
- The display name falls back to the `login` field if `name` is not set in the GitHub profile.
