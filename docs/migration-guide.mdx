# Migration Guide

## Session Management Rework (v1.1)

### New Endpoints

| Endpoint | Purpose |
|---|---|
| `GET /auth/sessions/all` | List **all** active sessions, no pagination. Returns `{ "sessions": [...], "current_session_id": "..." }`. |
| `POST /auth/sessions/revoke` | Revoke several sessions at once. Body `{ "session_ids": ["..."] }` (1–100). Returns `{ "revoked": n }`. |

### Breaking Changes

1. **`GET /auth/sessions` response shape changed.** Previously returned a bare array; now returns a paginated envelope:

```json
{ "sessions": [...], "total": 4, "limit": 20, "offset": 0, "current_session_id": "..." }
```

2. **Session JSON fields are now snake_case.** e.g. `user_id`, `ip_address`, `expires_at`, `last_active_at`, plus a new `parsed_ua` device object. Update clients that read the old `userId`/`ip`/`lastActiveAt` keys.

3. **`DELETE /auth/sessions/{id}` is user-scoped.** Sessions that don't belong to the caller now return `404 session_not_found` instead of being silently ignored. Malformed (non-UUID) IDs also return `404`.

4. **`DELETE /auth/sessions` keeps the current session.** It now revokes **all other** sessions, leaving the current device signed in.

5. **`Service.Session.List` is paginated.** Signature is now `List(ctx, userID string, offset, limit int) ([]domain.Session, int, error)`. The unpaginated variant is `ListAll(ctx, userID string) ([]domain.Session, error)`.

## v0.x → v1.0 (Org Invite Refactor)

### Breaking Changes

#### 1. `AddMember` Handler Removed

The `POST /auth/orgs/{orgID}/members` handler (`AddMember`) was removed. All membership must go through the invite flow.

**Before:** `POST /auth/orgs/{orgID}/members` with `{userId, role}`  
**After:** `POST /auth/orgs/{orgID}/invites` with `{email, role}` → user receives email → `POST /auth/orgs/invites/accept` with `{code}`

#### 2. `OrgService` Split

`OrgService` no longer has invite-related methods. Use `OrgInviteService` instead:

| Old | New |
|---|---|
| `OrgService.CreateOrgInvite` | `OrgInviteService.CreateOrgInvite` |
| `OrgService.AcceptInvite` | `OrgInviteService.AcceptInvite` |
| `OrgService.ListOrgInvites` | `OrgInviteService.ListOrgInvites` |
| `OrgService.DeleteOrgInvite` | `OrgInviteService.DeleteOrgInvite` |
| `OrgService.ResendOrgInviteEmail` | `OrgInviteService.ResendOrgInviteEmail` |

#### 3. File Renames

| Before | After |
|---|---|
| `service/org_service.go` | `service/org.go` |
| `service/org_invite_service.go` | `service/org_invite.go` |
| `sqlstore/org_repo.go` | `sqlstore/org_repo.go` + `sqlstore/org_queries.go` |

#### 4. `NewOrgService` Signature

Reduced from 8 to 5 params. Invite-related params removed.

**Before:**
```go
svc := service.NewOrgService(orgs, users, orgInvites, txManager, gen, mailer, config, logger)
```

**After:**
```go
svc := service.NewOrgService(orgs, users, txManager, config, logger)
orgInviteSvc := service.NewOrgInviteService(orgInvites, orgs, users, txManager, gen, mailer, inviteTTL, baseURL, appName, logger)
```

#### 5. OAuth Route Prefix

OAuth routes moved from `/auth/{provider}` to `/auth/oauth/{provider}`.

**Before:** `GET /auth/google`, `GET /auth/google/callback`  
**After:** `GET /auth/oauth/google`, `GET /auth/oauth/google/callback`

Update your frontend redirect URLs and API paths accordingly.

### Schema Changes

Run the migration SQL for existing databases:

```sql
-- Add org columns to users
ALTER TABLE users ADD COLUMN IF NOT EXISTS org_owner_count INTEGER NOT NULL DEFAULT 0;

-- Add active org columns to sessions
ALTER TABLE sessions ADD COLUMN IF NOT EXISTS active_org_id UUID REFERENCES organizations(id) ON DELETE SET NULL;
ALTER TABLE sessions ADD COLUMN IF NOT EXISTS active_org_role TEXT;
ALTER TABLE sessions ADD CONSTRAINT chk_active_org CHECK (
    (active_org_id IS NULL AND active_org_role IS NULL)
    OR (active_org_id IS NOT NULL AND active_org_role IS NOT NULL)
);

-- Fix verification_tokens CHECK to include delete_account
ALTER TABLE verification_tokens DROP CONSTRAINT IF EXISTS ...;
ALTER TABLE verification_tokens ADD CONSTRAINT ... CHECK(type IN (...'delete_account'));
```
