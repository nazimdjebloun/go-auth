# Security Policy

## Supported Versions

Only the latest tagged release (and `main`) receive security fixes —
this project is pre-1.0.

## Reporting a Vulnerability

Email djeblounnazim2@gmail.com with:

- A description of the issue and its impact
- Steps to reproduce (or a PoC)
- The affected version/commit

Please do not open a public GitHub issue for security reports.

## Reporting a Non-Security Issue

Regular bugs, feature requests, and everything else that isn't a
vulnerability should go through
[GitHub Issues](https://github.com/nazimdjebloun/go-auth/issues) as usual.

This is a solo-maintained project — expect a best-effort response, not a
guaranteed SLA. You'll be credited in the fix commit/release notes
